# CAIWAVE Portal UX v2

Portal presentation components live here.

Design principles:
- mobile-first
- premium visual hierarchy
- fast connection flow
- large touch targets
- minimal scrolling
- no business logic or API calls inside visual components unless explicitly required
- preserve payment, voucher, advert and MikroTik authentication contracts
